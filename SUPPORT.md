# Support

## Getting Help

AutoTabML Studio is a community-supported open-source project. Here is where to go
depending on what you need.

### Usage questions and troubleshooting

Start with the documentation:

| Resource | What it covers |
| --- | --- |
| [USAGE.md](USAGE.md) | Every page, every CLI command, every configuration knob |
| [docs/developer-guide.md](docs/developer-guide.md) | Local setup, common commands, test strategy |
| [docs/operations.md](docs/operations.md) | Day-1 verification, failure modes, reset procedures |
| [MIGRATION_GUIDE.md](MIGRATION_GUIDE.md) | Upgrading between versions |

If the docs do not answer your question, open a
[GitHub Discussion](https://github.com/pypi-ahmad/AutoTabML-Studio/discussions)
or a [Bug Report](https://github.com/pypi-ahmad/AutoTabML-Studio/issues/new?template=bug_report.yml).

### Reporting a bug

Use the [Bug Report template](https://github.com/pypi-ahmad/AutoTabML-Studio/issues/new?template=bug_report.yml).
Include your version (`autotabml info`), Python version, and the minimal steps to
reproduce the problem.

### Suggesting a feature

Use the [Feature Request template](https://github.com/pypi-ahmad/AutoTabML-Studio/issues/new?template=feature_request.yml).
Describe the problem you want solved and your preferred solution.

### Security vulnerabilities

Do **not** post security issues publicly. Report them privately through
[GitHub Security Advisories](https://github.com/pypi-ahmad/AutoTabML-Studio/security/advisories/new).
See [SECURITY.md](SECURITY.md) for the full policy and response SLA.

## What to Expect

This is a solo-maintained project. Response time for issues and PRs is best-effort.
There are no guaranteed SLAs for feature requests or non-security bugs. Patience and
a well-written bug report go a long way.

## Financial Support

This project is **free and will remain free**. The maintainer does not want, need,
or accept financial contributions, donations, or sponsorships. No GitHub Sponsors,
no Patreon, no buy-me-a-coffee link. If you want to give back, open a PR.

## Self-Hosted API Keys

Everything in AutoTabML Studio runs on your machine with your own credentials.
The project does not provide API keys, cloud accounts, or any hosted service.
You are responsible for obtaining and managing your own OpenAI, Anthropic, Gemini,
or Ollama setup. See [DISCLAIMER.md](DISCLAIMER.md) for the full data-responsibility
statement.
